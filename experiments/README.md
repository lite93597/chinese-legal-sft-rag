# 模型与实验层：legal-v4 SFT、RAG与评测

[仓库首页](../README.md) · [数据层](../data/README.md)

本层回答“数据如何进入模型、模型如何结合检索资料、效果如何测量”。它与数据层分开，不移动或重新划分已有SFT/RAG数据。

## 按流程阅读

| 部分 | 入口 | 已加入的实际材料 |
| --- | --- | --- |
| SFT训练 | [sft/README.md](sft/README.md) | 数据与消息组装、损失屏蔽、LoRA配置、训练完成记录 |
| RAG构建与推理 | [rag/README.md](rag/README.md) | 向量索引、候选融合、重排、版本与完整资料组装、实际预算 |
| 模型评测 | [evaluation/README.md](evaluation/README.md) | 四组消融协议、各基准成绩、分差、216条逐任务成绩与限制 |

本轮使用两套生成权重：原始模型用于Base/RAG，SFT模型用于SFT/SFT+RAG。RAG是检索增强流程；本轮没有重新训练BGE或Reranker，不能把“构建RAG索引”写成“训练了新的RAG模型”。

## 当前公开范围

已加入：原V4的实际配置、训练/检索/评测过程说明、训练摘要与实际成绩。统计文件从已完成的原实验记录中整理，不是新跑一次实验，也不混用V1/V2/V3结果。

尚未加入：完整训练、推理和收费评分工程源码，LoRA适配器/合并权重下载，以及第三方基准原始题目与答案包。现有配置是记录性配置，不是开箱即跑的完整复现入口；不提供虚假的训练命令或模型下载链接。

## 后续材料放在哪里？

- SFT训练代码、运行说明与模型发布信息：`sft/`，模型权重可通过独立模型托管链接提供，不混进 `data/sft/`。
- RAG检索器、重排与生成接线代码：`rag/`；语料和预建索引仍引用 `data/rag/`。
- 评测代码与协议：`evaluation/`；每轮结果放在 `evaluation/results/<实验版本>/`。本轮是 [v4](evaluation/results/v4/)。

新增实验应使用独立版本目录，不覆盖本轮成绩或改变数据层。公开模型和源码时仍需说明对应的基座、依赖及许可；本层文档不授予未持有的数据或模型权利。
